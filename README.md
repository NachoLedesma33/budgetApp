# Budget App / Aplicación de Presupuesto

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A simple and intuitive budget management application that helps you track your income and expenses.

## Project description / Descripción del Proyecto

This project is a budget management application that helps you track your income and expenses.

## Features / Características

- 💰 Set your initial budget / Establece tu presupuesto inicial
- ➕ Add income and expenses / Agrega ingresos y gastos
- 📊 View expense percentages / Visualiza porcentajes de gastos
- 📱 Responsive design / Diseño responsivo
- 🎨 Clean and modern UI / Interfaz limpia y moderna

## How to Use / Cómo Usar

1. **Set your budget** / **Establece tu presupuesto**
   - Enter your initial budget amount / Ingresa tu monto presupuestado inicial
   - Click "Set Budget" / Haz clic en "Set Budget"

2. **Add transactions** / **Agrega transacciones**
   - Select transaction type (Income/Expense) / Selecciona el tipo (Ingreso/Gasto)
   - Add description / Agrega una descripción
   - Enter amount / Ingresa el monto
   - Click "+" button / Haz clic en el botón "+"

3. **Track your finances** / **Monitorea tus finanzas**
   - View available budget / Ve tu presupuesto disponible
   - See total income and expenses / Revisa ingresos y gastos totales
   - Check expense percentages / Revisa los porcentajes de gastos

## Technologies / Tecnologías

- HTML5
- CSS3
- JavaScript (ES6+)
- Responsive Design / Diseño Responsivo

## Installation / Instalación

1. Clone the repository / Clona el repositorio

   ```bash
   git clone [repository-url]
   ```

2. Open `index.html` in your browser / Abre `index.html` en tu navegador
